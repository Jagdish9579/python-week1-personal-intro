
# Week 1: Python Basics - Personal Introduction Program

## About the Project
This is my Week 1 Python beginner project.
It is a simple Personal Introduction Program that
asks users questions and displays a friendly welcome message.

## Concepts Learned
- Python basics
- Variables and data types
- The input() function
- The print() function
- Strings and f-strings
- User input and output
- Comments in Python

## Features
- Asks for the user's name
- Collects age and favorite hobby
- Asks for city and favorite food
- Displays a personalized welcome message

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   python personal_intro.py

## Sample Output

    What is your name? Alex
    How old are you? 21
    What is your favorite hobby? Coding
    Which city do you live in? Pune
    What is your favorite food? Pizza

    Welcome, Alex!
    You are 21 years old.
    You live in Pune.
    Your favorite hobby is Coding.
    Your favorite food is Pizza.

## What I Learned
I learned how to collect user input, store information
in variables, and display personalized messages using Python.
